## 🎬 Movie Manager App

A simple and interactive React application to manage your favorite movies. Users can log in, browse a random movie list, and add movies to their favorites.
---

## 🚀 Features

🔐 Login Page – Secure login before accessing the app

🎞️ Random Movie List – Displays a list of random movies with posters

⭐ Favorites Manager – Mark and manage your favorite movies

📌 Navbar – Full-width responsive navbar with centered branding

💾 LocalStorage Support – Saves favorites and login session locally

🎨 Responsive UI – Clean, modern, and mobile-friendly design

---

## 🛠️ Tech Stack

React.js ⚛️

React Router DOM for navigation

Bootstrap / CSS for styling

LocalStorage for persistence
