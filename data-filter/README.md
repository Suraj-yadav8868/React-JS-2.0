# 📦 Orders Dashboard

A responsive **React + Bootstrap** based web app to manage and filter customer orders.
The app includes advanced filters, search functionality, and a modern UI for order management.

---

## ✨ Features

* 🔍 **Search & Filter Orders** (by ID, customer, phone, product, status, date, payment)
* 📊 **Status Tabs** (All, New, Completed, Cancelled, Pending)
* 📱 **Responsive Navbar** with badges and counters
* 🎨 **Bootstrap-based Modern UI** (with sticky navbar and action buttons)
* 📅 **Date-based Filtering**
* ✅ **Clear Filters Option** to reset search
